# 自媒体贴图流水线

本目录用于记录 HowToLiveBetter 仓库在 ChatGPT 网页版中的公众号贴图生产进度。

## 工作方式

1. ChatGPT 读取 `progress.json`。
2. 按 `current_chapter` 和 `next_item` 定位 `book/` 正文。
3. 默认连续读取 5 条；如用户指定数量，则按本轮数量执行。
4. 每条完整提取：标题、成本标签、成本、说人话、收益、证据等级、来源、备注。
5. 先生成本批“合集感”公众号标题。
6. 每条使用仓库中的“说人话”作为主要贴图文案，一条生成一张独立 3:4 贴图。
7. 全批图片成功生成后，把批次记入 `publish-log.md`，再推进 `progress.json`。
8. 图片未全部成功时，不推进游标。
9. 用户明确说“已发布”后，把对应批次状态从 `generated` 改为 `published`。

## 原则

- GitHub 是上游知识库，公众号贴图是传播层。
- 不随机挑选，不跳号，不因为传播性更强而改变仓库顺序。
- 文案以仓库抽取为主，合集标题允许创作。
- 不凭模型记忆替代实际读取。
- TODO、待核实、争议和适用条件不得静默删除。
- 本流程不依赖用户本地 Python、Git 或命令行脚本。
